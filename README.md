# LogSense

**LogSense** は Cosense (旧Scrapbox) のページを閲覧・操作できるシンプルな iOS アプリです。  
下部のタブバーから「ToDo」「Home」「Today」の各ページに切り替え可能。
https://scrapbox.io/jindazs/LogSense

---

## 主な機能

- **タブ切り替え**
  - 下部のカプセル型タブバーで 4 種類のページ（ToDo, Home, Today, Photos）を切り替え
    - ToDo: プロジェクト名/ToDo/
    - Home: プロジェクト名/
    - Today: プロジェクト名/YYYY-MM-DD
    - Photos: 写真プロジェクト名/
- **ジェスチャー操作**  
  - 各アイコンのダブルタップで各タブの初期ページにリセット  
  - Homeアイコンのトリプルタップで設定画面を表示
- **設定画面**  
  - プロジェクト名を設定可能
- **キーボード上のカスタムボタン**
  - 「Today」「Done」ボタンを追加し、月日挿入（#⚪︎月⚪︎日）やキーボードを閉じる操作を実装
- **共有シート拡張**
  - 最大20枚の画像を共有し、メインまたは写真プロジェクトを送信先として選択可能
  - 共有拡張では元画像を共有ストレージへ退避し、LogSense本体を開いている間に処理
  - Gyazo へ最大2件ずつアップロードし、Cosense のページに画像リンクをまとめて作成
  - アップロードの一時停止・再開・失敗分の再試行・未完了キューの管理に対応
  - 画像に EXIF の撮影日時があればその日付をページ名に使用し、無ければ現在日時を利用
